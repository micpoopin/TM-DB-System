### SQL Operations and Queries

1. CREATE_TABLE
> Create a table with attributes for each entity on the EERD.

2. INSERT
> Populates the tables with mock data.

3. DROP_TABLE
> Dropping all the tables.

4. FILE_1
> Display **one** `non-primary attribute` of each table and **all** data from joining two tables.

5. FILE_2
> Display **one** `data grouping` and **one** `data aggregation` from joining four tables with **two** additional data `selection constraints` from different tables.

6. FILE_3
> Display **two** `attributes` from each **six** tables with **three** additional data `selection constraints` from different tabless.

7. FILE_4
> Display **one** `attribute` from each **eight** tables in `descending order` with **four** additional data `selection constraints` from different tables.

8. FILE_5
> `VIEW` statement displaying **all** data of **three** `primary keys attributes` from joining **three** tables with **one** additional data `selection constraint` from different tables.
